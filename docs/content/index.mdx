  </Card>

  </Card>
  <Card title="Search that runs in the browser" href="/features/search">

    search service is involved.
  </Card>

    Every site gets `llms.txt`, `llms-full.txt` and an MCP endpoint, so coding agents can search and read the docs.
  </Card>
  <Card title="Edit in the browser" href="/features/studio">

    updates as you type.
  </Card>

  </Card>

## What a site looks like

```text
my-docs/
├── shabd.config.yaml   site, theme, layouts, features
├── sidebar.yaml        navigation
└── content/
    ├── index.mdx
    └── guide/
        └── introduction.md
```

```yaml title="shabd.config.yaml"
site:
  title: My docs

theme:
  colors:
    accent: "#2b36a8"

features:
  search: { semantic: true }
  mcp: true
```
